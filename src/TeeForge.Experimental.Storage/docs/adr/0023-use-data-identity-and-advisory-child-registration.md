# Use data identity and advisory child registration

TeeForge block streams expose a stable stream identifier and a data write identifier that changes before the first caller-visible mutation of a writable open; differencing children capture both and validate them only when created or opened, while callers supply equivalent identity for other base-stream types. An opt-in creation notification records each immediate child's stable identifier in its base through an idempotent journaled registry, but the advisory entries may become stale, do not prevent upstream writes, and never change logical data identity. This follows VHDX-style parent invalidation while keeping ordinary differencing I/O strictly downstream-only and allowing read-only or nonregistrable bases when notification is disabled.
