# Security

Report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/DouglasCleghorn/TeeForge/security/advisories/new).
Include the affected TeeForge version, a minimal reproduction, and the
expected and observed behavior. Omit credentials, private keys, and personal
data from reproductions. Use public issues for ordinary bugs and feature requests.

TeeForge is in prerelease. Security fixes target the latest available release;
there are no long-term support or backport commitments during the 0.x series.
